# 长高鹿产品网站

静态 HTML / CSS，无构建工具、JavaScript、远程字体或分析脚本。可直接打开 `index.html`，或将整个 `website/` 目录放到静态网站托管服务中，保留文件相对路径。

## 页面

- `index.html`：产品介绍、功能、测量指南、原生折叠问答与下载状态。
- `privacy.html`：隐私协议（待发布草稿），含本地信息清单、相机、友盟统计、儿童信息及权利管理。
- `terms.html`：用户协议（待发布草稿），含功能范围、测量边界、记录管理及使用约定。
- `styles.css`：三页共享样式，包含手机适配、键盘焦点、减少动态效果与协议打印样式。
- `assets/`：从现有品牌资源复制的插画和图标。

## 内容依据

保留原始需求和设计文件。页面结合 `specs/ar-height-ios.spec.md`、`design/README.md`、`docs/implementation-status.md`、当前 SettingsView / AppDelegate / 数据模型及 CDC 说明编写。最新实现优先于早期范围：品牌为“长高鹿”；CDC 0–20 岁参考已加入；可选友盟统计默认关闭，通过设置开启，启动时没有授权提示页。

不会宣传保证精度、医学诊断、婴幼儿 AR 测量、云同步、导出恢复或已经上线的下载地址。网站介绍功能，不代表已完成 AR 真机精度验收。

## 正式发布时需要补齐

1. 在两份协议的联系章节填写实际运营主体、有效支持邮箱、生效日期；将联系方式改为可用的邮件链接。
2. 在首页下载区域填写已确认的 App Store URL，将“链接待提供”状态替换为真实下载链接。
3. 按当前友盟 iOS SDK 官方披露、实际配置及网络验证，确认提供方、精确采集字段、保存地区和期限、关闭后的缓存及网络行为；替换隐私协议对应待核对描述。
4. 确定正式托管服务后，填写网站访问日志的服务商、用途及保存期限。
5. 以上事实确认后更新版本与日期、移除草稿提示、待补充标识及两份协议的 `noindex` 标签。如需在 App 内使用协议，应在获得正式 HTTPS 地址后另行接入；本次没有修改 App 的隐私入口。

全文查找 `待填写`、`待确认`、`待补充`、`待提供`、`待发布`、`待核`、`发布前`、`草稿` 和 `noindex` 可定位发布相关项。
