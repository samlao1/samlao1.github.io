# 岗位资格考试题库网页

这是从 `【发送1105】【汇总版】2026年岗位资格考试题库.xlsx` 解析出的离线答题页，共 200 题：100 道单选题、32 道多选题、68 道判断题。

## 打开方式

在当前目录启动一个静态文件服务，然后访问 `http://localhost:4173`：

```bash
python3 -m http.server 4173
```

也可以直接双击 `index.html` 打开。使用静态服务时，题库数据和页面资源加载会更稳定。

## 已支持功能

- 答题模式：单选、多选、判断，提交后即时批改并显示解析。
- 答案模式：直接查看正确答案、选项高亮和试题解析。
- 题型筛选、题号跳转、随机抽题、键盘左右方向键切题。
- 使用浏览器 `localStorage` 自动保存当前题号、已选答案、提交结果和错题记录。
- 错题本：集中查看答错题目，点击题目可直接回到对应练习。
- 重置记录：清空答题进度、答案和错题本。

记录保存在当前浏览器中。请使用同一浏览器和同一打开地址继续练习；更换设备、浏览器、打开地址或清除浏览器数据不会保留原进度。答案模式只用于阅读，不计入已完成题数。错题本保留曾经答错的题目，重新答对后仍可复习，重置记录时一并清空。

## 重新解析 Excel

如果替换了同目录下的题库 Excel，可运行：

```bash
python3 scripts/parse_questions.py
```

脚本会重新生成 `data/questions.js`，页面无需改动即可使用新题库。

解析脚本依赖 `openpyxl`。替换题库后，请在页面重置旧记录，以免旧题号对应到不同题目。
