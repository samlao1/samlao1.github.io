MM远程隐私政策

生效日期：2026年7月9日　更新日期：2026年7月9日
我们深知个人信息对你的重要性。本政策说明 MM远程 如何收集、使用、存储、共享、转让、公开披露和保护你的个人信息，以及你如何管理个人信息权利。运营主体、联系方式、第三方 SDK 清单等请在上线前按实际情况补全。

一、适用范围

本隐私政策适用于 MM远程 App、电脑端、官网、会员服务、房间共享、远程连接、问题反馈及我们向你提供的相关服务。

第三方网站、游戏、应用、支付平台或登录平台可能有独立的隐私政策。你通过 MM远程 访问或使用第三方服务时，请同时阅读第三方规则。

二、我们如何收集和使用个人信息

我们遵循合法、正当、必要、诚信原则，仅为实现产品功能和服务目的收集必要信息。

三、设备权限调用

我们仅在你使用相关功能时申请系统权限。你可以在设备系统设置中管理或撤回授权，但撤回后相关功能可能无法正常使用。

相机 扫码登录、扫码加入房间、拍摄反馈图片或头像 可拒绝；拒绝后扫码或拍摄功能不可用
相册/照片 选择头像、上传图片、保存或选择反馈截图 可拒绝；拒绝后无法从相册选择或保存相关内容

网络与本地网络 连接服务器、远程音视频传输、账号登录、文件上传、局域网连接能力 网络为服务必要条件，关闭后无法联网使用

四、我们如何使用 Cookie 和同类技术

官网可能使用 Cookie、本地存储或同类技术记录语言、访问状态、页面统计和安全信息。你可以通过浏览器设置管理 Cookie；禁用后部分网页功能可能受影响。

五、我们如何委托处理、共享、转让、公开披露个人信息

1. 委托处理

为提供服务器托管、日志分析、支付结算、客服支持、消息推送、统计分析等服务，我们可能委托合作方处理必要信息。我们会要求合作方按照约定、法律法规和本政策处理个人信息。

2. 共享

除以下情形外，我们不会向第三方共享你的个人信息：

  • 获得你明确同意或授权。
  • 为实现 QQ、微信、Apple 登录/分享/支付、App Store 订阅、消息推送、崩溃分析、统计分析等功能所必需。
  • 为履行法定义务、司法或行政机关要求、安全风控、处理纠纷所必需。
  • 在合并、分立、收购、资产转让、破产清算等交易中依法进行转移，并要求新的持有方继续受本政策约束。

3. 第三方 SDK

项目可能集成 QQ/微信开放平台、Apple、友盟统计、Bugly 崩溃分析、Logan 日志、图片加载、网络请求等 SDK 或组件。请在上线前根据实际集成版本补充完整 SDK 名称、提供方、收集信息类型、使用目的和隐私政策链接。

4. 公开披露

我们不会公开披露你的个人信息，除非获得你的单独同意，或基于法律法规、行政执法、司法要求必须披露。

六、我们如何存储和保护个人信息

  • 我们会在实现本政策所述目的所需的最短期限内保存你的个人信息，法律法规另有规定的除外。
  • 我们主要在中华人民共和国境内存储境内用户个人信息。若因跨境业务、海外版服务或境外基础设施需要向境外提供个人信息，我们会按照适用法律履行必要程序。
  • 我们会采取加密传输、权限控制、访问审计、日志记录、最小权限、备份恢复等合理安全措施保护个人信息。
  • 互联网环境并非绝对安全。若发生个人信息安全事件，我们会按照法律法规要求告知你事件情况、可能影响、已采取措施、你可采取的防范建议和联系方式。

七、你的个人信息权利

在法律法规允许范围内，你可以行使以下权利：

  • 查询、更正或补充账号资料、昵称、头像等个人信息。
  • 删除你主动上传的部分内容或请求我们删除个人信息。
  • 撤回系统权限授权，如相机、相册、麦克风、通知等。
  • 注销账号。注销后，我们将停止为你提供相关服务，并依法删除或匿名化处理你的个人信息，法律法规另有规定的除外。
  • 获取隐私政策解释、投诉、举报或撤回同意。

你可以通过 App 内“我的 - 设置/关于我们/问题反馈/联系客服”等路径或本政策列明的联系方式联系我们。为保障账号安全，我们可能需要验证你的身份。

八、未成年人个人信息保护

我们非常重视未成年人保护。未成年人使用 MM远程 应取得监护人同意并在监护人指导下进行。若你是未成年人的监护人，发现未成年人未经同意向我们提供个人信息，可联系我们处理。

九、政策更新

我们可能根据法律法规、产品功能或运营情况更新本政策。涉及个人信息权益重大变化时，我们会通过弹窗、页面提示、站内公告或其他合理方式通知你。若你继续使用服务，即表示你接受更新后的政策。

十、联系我们

如你对本政策或个人信息保护有疑问、投诉、建议，或希望行使个人信息权利，可通过以下方式联系我们：
